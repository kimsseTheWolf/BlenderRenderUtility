# BRender

Simple tool to render your blender stuff without entering all of the annoying commands. More amazing features in the future.

## Install

All you need is to run the `install.sh` under this directory:

```sh
chmod +x ./install.sh
./install.sh
```

# How to use?

To start off, type `brender` in your terminal, brender will guide you through some simple steps to set everything up. Follow the prompts provided by `brender`

After setting up, type `brender` again, and it will start the render job wizard for you. Just fill in the information, and leave all of the other jobs to brender!
